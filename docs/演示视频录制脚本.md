# AI PCB 设计助手 · 演示视频录制脚本

> 目标：3–5 分钟真实录屏，从「输入一句话」到「用 KiCad 打开原理图」，可配旁白/字幕。
> 时长设计：约 4 分 30 秒（8 个镜头）。口播词已按正常语速写好，可直接照读。

---

## 一、录制前准备

- **服务**：确认后端已启动（`python web/server.py`），浏览器打开 `http://127.0.0.1:8000`。当前机器 8000 端口已在监听，直接开浏览器即可。
- **KiCad**：确认已安装 KiCad 8，最后一个镜头要用它打开原理图。
- **演示模式**：全程勾选「离线模式（无需密钥，用内置示例）」——稳定、不依赖网络，口播里说明「也支持接真实大模型」即可。
- **浏览器**：窗口全屏或最大化，缩放 100%–125%（字要观众看得清），关掉通知和无关标签页。
- **录屏**：1080p / 30fps，同时录系统声音和麦克风。
- **剪辑**：生成的等待段（转圈 30–90 秒）可 4 倍速，但**保留 2–3 秒原速进度**，以体现「全程真实录屏」；其余镜头原速。

## 三、逐镜脚本

### 镜头 1｜开场点题（0:00–0:20）

**画面**：网页首页静止，鼠标停在需求输入框上，不操作。

**口播**：
> 这是 AI PCB 设计助手。我教会 AI 做一件事：用一句中文需求，自动生成 BOM、引脚级网表和 KiCad 原理图，并且自动跑完四道检查。下面我从输入一句话开始，一路演示到用 KiCad 打开生成的原理图。

**字幕**：一句话 → BOM · 网表 · KiCad 原理图 → 四检闭环

---

### 镜头 2｜入口与环境（0:20–0:45）

**画面**：鼠标移到地址栏停留 2 秒（让观众看清 `127.0.0.1:8000`），然后缓慢下移到输入区，让页面标题和四个快捷示例入镜。

**口播**：
> 系统完全本地运行，数据不出这台机器。后端复用和命令行一模一样的 Agent 流水线，网页只是把它可视化。最上面是需求输入框，下面四个快捷示例可以直接点，我演示用第一个。

**字幕**：本地运行 · 数据不出本机 · 后端复用同一 Agent 流水线

---

### 镜头 3｜一句话生成（0:45–1:30）

**画面**：
1. 点击快捷示例「帮我设计一块 Arduino 最小系统板」——文字自动填进输入框。
2. 勾选「离线模式（无需密钥，用内置示例）」——「规则检查闭环」保持默认勾选。
3. 点击右下角蓝色「生成原理图」按钮。
4. 出现「正在调用 AI Agent 设计…（首次约 30–90 秒）」转圈。

**口播**：
> 我点这个示例，需求就填好了。勾上离线模式，不需要密钥也能跑通；实际使用时也可以接真实大模型。点生成——Agent 会先选器件做 BOM，再连引脚做网表，最后写出 KiCad 原理图。首次大约几十秒，我这里保留几秒真实进度，后面剪辑会加速。

**剪辑**：转圈等待段 4 倍速，保留 2–3 秒原速。

**字幕**：需求 → Agent 编排 → BOM → 网表 → KiCad 原理图

---

### 镜头 4｜四检徽章（1:30–2:00）

**画面**：结果区顶部那一排彩色徽章，鼠标依次轻点/悬停：
「数据来源：离线知识库」→「ERC：0 违规 ✓」→「布局：无重叠 ✓」→「功能自检通过 ✓」→（若有）「已自动修正 N 处电路」。

**口播**：
> 生成完先看这一排徽章。ERC 0 违规，说明原理图能被 KiCad 正确解析、电气规则没问题；布局无重叠，是自动查文字压线、导线穿符号；功能自检通过，查的是 ERC 查不出的限流、极性和电压匹配。如果这行出现「已自动修正」，点开就能看到系统替你补了哪些连接——这些功能性错误，ERC 是不会报的。

**字幕**：ERC 0 违规 · 布局 0 重叠 · 安全告警 0 · 功能自检通过

---

### 镜头 5｜三份产物一致性（2:00–2:45）

**画面**：依次点击四个标签：
1. **原理图预览**：点一次「＋」放大，再点「适应宽度」复位。
2. **BOM 清单**：让位号、符号、标称值几列入镜。
3. **引脚级网表**：让网络名和它连接的引脚入镜。
4. **ERC / 闭环日志**：展开「布局自检（自动，无需截图）」卡片，露出明细。

**口播**：
> 四个标签对应四份产物。原理图预览是 KiCad 导出的 SVG，可以缩放拖动；BOM 清单列位号、符号和标称值；引脚级网表列出每条网络连到哪些脚。三者同源生成，位号一致。最后是 ERC 和闭环日志，能看到迭代了几轮、每轮多少违规，还有布局自检明细——全部自动，不用人工截图找问题。

**字幕**：BOM / 网表 / 原理图同源一致 · 闭环日志可追溯

---

### 镜头 6｜对话式修改（2:45–3:35）

**画面**：
1. 在「对话式修改 · 更换元件」输入框输入「把 C1 换成 22uF」（或点下方同名快捷块）。
2. 点击「应用修改」。
3. 结果整体刷新后，切到 BOM 标签，指一下 C1 的标称值已变；再回到徽章区，确认四检仍全绿。

**口播**：
> 更实用的是可以继续改。我输入「把 C1 换成 22uF」，点应用。注意它不是重新画一张图，而是在同一个会话里做增量修改——BOM、网表、原理图、四检报告一起更新，位号不会错位。涉及电源电压这类高风险改动，系统会先弹窗让你确认，因为 ERC 查不出电压是否匹配。

**字幕**：对话式增量修改 · 三份产物同步 · 高风险指令二次确认

---

### 镜头 7｜KiCad 打开原理图（3:35–4:15）

**画面**：
1. 回到结果区，在徽章行末尾找到「原理图：<路径>」，用鼠标高亮选中该路径。
2. 打开 KiCad 8，用「文件 → 打开」载入这个 `.kicad_sch` 文件。
3. 展示符号、连线、网络标签，放大一个芯片区域停留 2 秒。

**口播**：
> 最后一步，也是关键：这不是一张图片，而是原生的 KiCad 8 原理图文件。我把页面显示的路径复制到 KiCad 里打开——符号、连线、网络标签、属性都是真的，可以直接改、跑 DRC、继续导出 PCB。从一句话到这里，闭环完成。

**字幕**：原生 .kicad_sch · 可二次编辑 / DRC / 导出 PCB

---

### 镜头 8｜收尾（4:15–4:30）

**画面**：网页与 KiCad 窗口并排（或回到网页全屏），定格 2 秒。

**口播**：
> 总结：一句话需求，自动生成 BOM、网表和 KiCad 原理图，ERC、布局、安全、功能四检全绿，还能对话式修改。这就是我教会 AI 做的事。谢谢。

**字幕**：一句话 → 可用原理图 · 四检闭环 · 可追溯可修改

## 四、常见意外与补救

| 情况 | 处理 |
|---|---|
| 生成慢或超时 | 保持离线模式；首次 90 秒内属正常，不要重复点生成 |
| 徽章不是全绿 | 换用快捷示例里的 Arduino 最小系统板（最稳定）；不要用自造的复杂需求录制 |
| 页面白屏 | 确认 8000 端口服务在跑，刷新页面 |
| KiCad 打不开文件 | 确认安装的是 KiCad 8；路径从页面「原理图：」后面复制，不要手敲 |
| 弹出风险确认框 | 正式录制避开「稳压器/电压」类指令；若想展示安全特性，可保留这个弹窗作为亮点 |
| 鼠标抖动、点击太快 | 每个点击前后停顿 0.5 秒，移动放慢，便于观众跟上 |

## 五、口播节奏提示

- 全稿约 550 字，按每分钟 180–200 字约需 3 分钟；加上操作停顿，总时长约 4–4.5 分钟，正好落在 3–5 分钟要求内。
- 旁白与字幕二选一或同时都有均可（课程要求「可配旁白/字幕」）；若只配字幕，把上面「口播」段直接当字幕贴入剪辑软件。
- 录完检查三处硬指标是否入镜：**ERC 0 违规徽章**、**四检徽章全绿**、**KiCad 里打开的原理图**——这三点缺一，演示就讲不清「你教会 AI 做了什么」。
